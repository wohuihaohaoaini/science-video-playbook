# 错误检验清单

每一项都写明：**检查什么、怎么查、不过关时的现象**。按阶段排列，前一阶段不过关就不要进下一阶段。
带 🔧 的项有脚本自动检查，其余靠人（或 Claude）目视判断。

---

## 0 · 环境（`make preflight`，在**实际渲染的那个环境**里运行）

| # | 检查 | 方法 | 不过关时的现象 |
|---|---|---|---|
| 0.1 🔧 | 无头 Chrome 能启动 | `preflight.py` 启动 `channel="chrome"` | `TargetClosedError`，Chrome 收到 SIGABRT，崩溃栈里有 `TransformProcessType`：说明在进程沙盒里，换到沙盒外运行 |
| 0.2 🔧 | VideoToolbox 能建立编码会话 | 用 `h264_videotoolbox` 编 1 帧 | `-12903`：多半也是沙盒，会自动退回 libx264（慢 2–3 倍） |
| 0.3 🔧 | 字体文件齐全 | 对照 `index.html` 的 @font-face 逐个查 | 画面悄悄换成系统字体，字重和字宽都不对 |
| 0.4 🔧 | 照片齐全 | 对照 `film.js` 里的 `*.jpg` 引用 | 渲染模式下 `filmReady()` 直接报错；预览模式下显示灰色占位图 |
| 0.5 🔧 | 每句旁白都有音频文件 | 对照 `narration.json` | `vo_durations.py` 报 missing |
| 0.6 | 用 Agent 执行时的权限 | 给 Codex 加 `--dangerously-bypass-approvals-and-sandbox` | 能写代码，但一帧都渲不出来（2026-10 实测） |

## 1 · 内容与事实

| # | 检查 | 方法 | 不过关时的现象 |
|---|---|---|---|
| 1.1 🔧 | 每个 DOI 都能解析，元数据一致 | `make refs`（对照 Crossref；人工核实过的例外写进 `crossref_known_issues`） | 期刊、年份、页码对不上；出现 `CERTIFICATE_VERIFY_FAILED` 是证书问题，不是 DOI 错误 |
| 1.2 | Crossref 自身也可能登记错 | 有不一致时再查 PubMed 或出版社页面 | 例：Onda 2008，Crossref 页码 323–324，PubMed 为 636–645 |
| 1.3 | 物种、分布、海拔有一手来源 | 查《中国植物志》（FOC）、POWO | 例：需求里的“高原湿地臭菘”，实际海拔在 300 m 以下 |
| 1.4 | 相似名称不能混用 | 学名逐一对照 | 死马海芋（*Helicodiceros*）≠ 海芋（*Alocasia*） |
| 1.5 | 一个物种的现象不能推广到所有物种 | 每个物种单列生境和作用 | 把臭菘的雪地产热套到热带物种上 |
| 1.6 | 机制表述不绝对化 | 台本逐句标注依据（`01_台本与事实核对.md`） | “不产生 ATP”“全部变成热”这类说法 |
| 1.7 | 示意图要标注“示意” | 画面上加注 | 观众会把示意曲线当成实测数据 |
| 1.8 | 照片物种正确、授权可用 | 查 Commons 分类页，记录到 CREDITS.md | 用近缘种冒充（例：北美 *S. foetidus* 的雪景） |

## 2 · 旁白与时间线

| # | 检查 | 方法 | 不过关时的现象 |
|---|---|---|---|
| 2.1 | 字数预算 | 中文 TTS 约每秒 4.6 字（edge-tts，+6% 语速） | 总时长超出或不足 |
| 2.2 🔧 | 改台本后重新录音、重新测时长 | `make voice durations prepare` | `mix.py` 报某句比时间线里的槽位长 |
| 2.3 | 重新编号时，不要让旧音频错配到新句子 | 先备份 `audio/vo_v1/`，倒序重命名 | 字幕和配音对不上 |
| 2.4 🔧 | 时间线只有一个来源 | `build/timeline.json` 必须带 `source=chrome-filmReady` | 用 Python 复刻 JS 的规则，两边漂移 |
| 2.5 🔧 | 总长不少于下限，参考文献段长度准确 | `check.py` | — |

## 3 · 画面（在浏览器里预览：`make preview`，打开 `?preview=1`）

| # | 检查 | 方法 | 不过关时的现象 |
|---|---|---|---|
| 3.1 | **字幕安全区** | 两行字幕的顶部约在 y = 888；正文内容必须在 y < 860 以内 | 图注、结论文字被字幕压住（本项目出现过 5 次） |
| 3.2 | 每场在每句话中点各抽一帧 | 用 `renderFrame(at('Lxx', d))` 后截图 | 文字互相覆盖 |
| 3.3 | 标签不能挤在一起 | 放大检查标签附近 | 例：“INTERMEMBRANE SPACE”撞上了复合体 I 的标注 |
| 3.4 | 动画的起始值不能有歧义 | 检查数字滚动的起点 | 例：气温从 “+4” 滚到 −5，被误读成实测气温 |
| 3.5 | 照片的裁切焦点 | 竖图塞进横框时调 `fy` | 主体（花序）被切掉 |
| 3.6 | 装饰元素裁剪在照片框内 | 用 `clipRect` 包住 | 气味圆环画进了页眉 |
| 3.7 | 预览缓存 | `film.js?v=Date.now()` | 改了代码，浏览器还在显示旧版本 |

## 4 · 渲染

| # | 检查 | 方法 | 不过关时的现象 |
|---|---|---|---|
| 4.1 🔧 | 先出一张图，再出样片，最后出全片 | `make still` → `make sample` → 人工通过 → `make full` | 全片渲到一半才发现问题 |
| 4.2 🔧 | 并发启动时资源加载要稳 | `pipeline/serve.py`（backlog 256）+ `open_page` 重试 + `film.js` 中 `getJSON` / `loadImg` 带重试 | 偶发 `filmReady is not defined` 或 `Cannot read properties of null (reading 'lines')` |
| 4.3 🔧 | 照片加载失败时直接报错 | 渲染模式下缺图就 throw | 占位图混进成片 |
| 4.4 | 运动模糊 | 每帧 4 个子帧、180° 快门；静止画面应保持锐利 | 参考文献页发糊 |
| 4.5 🔧 | 根据样片实测速度估算全片耗时 | `sample_review.json` 里的 `estimated_full_seconds`；先看 `uptime`，确认机器空闲 | 机器负载高时慢 8 倍 |

## 5 · 声音

| # | 检查 | 方法 | 不过关时的现象 |
|---|---|---|---|
| 5.1 🔧 | 配乐与时间线一致 | `audio_metrics.json` 中的 `timeline_sha256` | 改了时间线却没重新生成配乐，段落错位 |
| 5.2 🔧 | 响度 −16 LUFS ±0.5，真峰值 ≤ −1 dBTP | 两遍 loudnorm，再用 `ebur128` 复测 | 平台二次压缩，或爆音 |
| 5.3 | 旁白出现时配乐压低（ducking） | −8 dB，起音 60 ms，释放 400 ms | 配乐盖住人声 |
| 5.4 | 音效比人声低 10–14 dB | 按 RMS 自动对齐 | 音效抢戏 |

## 6 · 成片（`make check`）

| # | 检查 | 方法 |
|---|---|---|
| 6.1 🔧 | 1920×1080、30 fps、H.264、yuv420p、BT.709、AAC 48 kHz 立体声 | 用 `ffmpeg -i` 读流信息 |
| 6.2 🔧 | 帧数严格等于 ceil(总时长 × 30) | 完整解码一遍计数 |
| 6.3 | 每场中点和参考文献两屏都抽帧，**全尺寸**放大看文字锐度 | `build/check/*.png`、`contact.jpg` |
| 6.4 | 封面是 1920×1080 的 PNG，主标题醒目 | `out/cover.png` |
| 6.5 | 简介里的章节时间点取自 `timeline.json` | 和成片对照 |
