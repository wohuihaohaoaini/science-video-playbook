# 声音设计（设计：克拉克；程序合成与混音：Codex）

基调：克制、干净，像一张瑞士海报配上一段极简的电子乐。全部用程序合成（numpy / scipy），不用任何外部采样。

## 配乐

- 调性 D 小调，速度 96 BPM（1 拍 = 0.625 s），全片约 240 s。
- 层次：
  1. **Pad**：两到三个正弦波叠加，带轻微失谐（±3 cent），和弦进行 Dm9 → Bbmaj7 → Fmaj7 → C6，每 4 小节换一次；低通约 2.5 kHz，起音和释放都长（2 s）。
  2. **Pulse**：八分音符的短促正弦"嘀"（D5 和 A5 交替），衰减约 80 ms，音量很低，从 S3 开始进入，象征电子流动。
  3. **Bass**：S5 之后加入的正弦低音，跟随和弦根音，每小节一个音。
- 段落强度（相对电平）：
  - S1 冷开场：只有 Pad，−26 LUFS 左右的背景感
  - S2 标题：Pad 加一个低频 hit
  - S3–S4：加入 Pulse；S4 氰化物出现时 Pulse 突然停 1 小节（制造"中断"）
  - S5：Pulse 恢复，Bass 进入
  - S6–S8：维持
  - S9 暗场：去掉 Pulse，Pad 低通降到 1.2 kHz
  - S10：全部层次回来，最后一句结束后用 4 s 渐弱
  - S11 参考文献：只留 Pad，12 s 内自然淡出到静音，在 240 s 处正好结束
- 有旁白时配乐自动压低（sidechain ducking）：比无旁白时低 8 dB，起音 60 ms，释放 400 ms。

## 音效（触发点由时间线 cue 决定，位置见 `scenes/film.js` 中的 `SFX_CUES`）

| 名称 | 合成方法 | 用在哪里 |
|---|---|---|
| `tick` | 2 kHz 正弦波，持续 15 ms，指数衰减 | 文字或数字落位、模块进场 |
| `sweep` | 白噪声加带通滤波，中心频率在 0.5 s 内从 400 Hz 扫到 3 kHz | 转场的红色划线 |
| `thud` | 55 Hz 正弦波，带 120 ms 衰减和少量谐波失真 | 氰化物落下（S4） |
| `branch` | 两个正弦波向上滑音（D4→A4），持续 0.4 s | AOX 支路打开（S5） |
| `warm` | 粉红噪声加低通，1.5 s 起音 | 产热、温度上升（S1、S7） |
| `pop` | 很短的噪声 click，带高通 | ROS 迸出（S9），每次音量随机在 −6 到 0 dB |

## 混音目标

- 旁白：在 −16 LUFS 总响度下保持清晰，峰值不超过 −1 dBTP。
- 音效：比旁白低 10–14 dB，不抢旁白。
- 输出：AAC 320 kbps，48 kHz，立体声（旁白居中，Pulse 左右轻微交替声像 ±15%）。
