# 验收记录（设计负责人：克拉克）

## B 阶段阻塞的诊断
- 限制来自 **Codex 的执行沙盒**（`codex exec -s workspace-write`，approval=never），与 Claude 本身无关。
- 失败命令：`.venv/bin/python pipeline/render.py prepare`（在 Codex 沙盒内运行）。错误：Playwright 报 `BrowserType.launch: TargetClosedError`，Chrome 收到 SIGABRT，崩溃栈为 `_RegisterApplication` / `TransformProcessType` / `ChromeMain`，即沙盒禁止 Chrome 向 WindowServer 注册。完整日志见 `build/codex_B.log` 第 2343–2581 行和第 3473–3783 行。
- 硬件编码在沙盒内同样失败：`h264_videotoolbox` 报 `cannot create compression session: -12903`（`build/encoder_probe.log`，退出码 187）。
- Codex 内置浏览器工具对 localhost 的访问请求，在 approval=never 下被自动拒绝。
- 同样的命令在 Claude 的本机 Bash 里运行全部成功：Chrome 正常启动，VideoToolbox 探测返回 0。

## 实测性能（Apple M5，7 个 worker，每帧 4 个子帧，h264_videotoolbox）
- 10 秒样片（300 帧）：11.4 秒
- 全片（7452 帧）：297 秒（第一版），272 秒（修正版）
- 混音加两遍 loudnorm：11 秒
